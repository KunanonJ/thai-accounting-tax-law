# 🇹🇭 บัญชี ภาษี และกฎหมายธุรกิจไทย

[English](README.md) · **ภาษาไทย**

**ภาษี SME ไทย อธิบายแบบไม่ปวดหัว ทุกตัวเลขมีที่มา** 🧾

คุณมี หจก. หรือ บจก. อยู่ หรือกำลังจะเปิด ได้ยินคำว่า "ภ.ง.ด.53" "50 ทวิ" "VAT 7%… แต่เดี๋ยวก็เปลี่ยน?" แล้วได้แต่พยักหน้า repo นี้คือชีทสรุปฟรีแบบเปิดที่เราอยากมีตั้งแต่วันแรก: ต้องจ่ายอะไร ใช้แบบไหน ภายในวันไหน และ *กฎข้อนี้มาจากไหน*

ใช้ได้ทั้งเป็นคู่มือให้คนอ่าน **และ** เป็น AI skill ที่เสียบเข้า Claude, ChatGPT หรือ agent ของคุณเองได้ จะได้คำตอบที่มีแหล่งอ้างอิง ไม่ใช่การเดาแบบมั่นใจ

> ⚠️ **พูดกันตรง ๆ ก่อน:** นี่คือข้อมูลอ้างอิง ไม่ใช่คำปรึกษาทางกฎหมายหรือภาษี กฎไทยเปลี่ยนบ่อย บางเรื่องเปลี่ยนทุกปี ก่อนยื่น จ่าย หรือเซ็นอะไร ให้เปิดดูแหล่งที่ลิงก์ไว้ และให้นักบัญชีหรือผู้สอบบัญชีรับอนุญาตยืนยันอีกครั้ง
>

## ✅ ทำไมเชื่อได้ (และตอนไหนที่ไม่ควรเชื่อ)

เราอยากให้มีประโยชน์จริงมากกว่าดูฉลาด เลยทำแบบนี้:

- **ทุกบรรทัดมีที่มา** อัตรา กำหนดเวลา และกฎทุกข้อลิงก์ไปที่ต้นทาง: กรมสรรพากร ราชกิจจานุเบกษา กรมพัฒนาธุรกิจการค้า ธปท. PwC ฯลฯ ดูได้ที่[หน้ารวมแหล่งอ้างอิง](skills/thai-accounting-tax-law/references/sources.md)
- **บอกระดับความมั่นใจ** **[V]** ตรวจกับแหล่งทางการแล้ว · **[S]** แหล่งรองที่น่าเชื่อถือ · **[U]** ยังไม่ยืนยัน ให้ถามนักบัญชี
- **ไม่รู้ก็บอกว่าไม่รู้** เรื่องไหนหาคำตอบที่ชัวร์ไม่ได้ (เช่น ภ.พ.36 สำหรับบริษัทที่ไม่ได้จด VAT 👋) เราเขียนตรง ๆ ว่ายังไม่ชัด ไม่แต่งขึ้นเอง
- **โชว์วิธีคิด** มีตัวอย่างคำนวณทีละบรรทัด ตรวจตามได้เอง
- **บอกวันหมดอายุ** VAT 7%, e-WHT 1% และยื่นออนไลน์ +8 วัน เป็นมาตรการชั่วคราวทั้งหมด รวมไว้ใน[ตารางเดียว](skills/thai-accounting-tax-law/references/06-filing-calendar.th.md)
- **ไม่มีข้อมูลส่วนตัว** ไม่มีเลขผู้เสียภาษี เลขบัญชี หรือข้อมูลลูกค้าจริง
- **เปิดให้แก้ได้** ใช้สัญญาอนุญาต MIT เจอจุดผิด เปิด issue พร้อมแหล่งอ้างอิง แล้วเราจะแก้และบันทึกไว้ใน[บันทึกการเปลี่ยนแปลง](CHANGELOG.md)

## ⚡ ตัวเลขที่คนถามบ่อยที่สุด (ณ 15 พ.ย. 2569)

| เรื่อง | ตัวเลข | ข้อควรรู้ |
|---|---|---|
| ภาษีเงินได้นิติบุคคล | **20%** | SME เสียน้อยกว่า (แถวถัดไป) |
| อัตรา SME | กำไร 300,000 บาทแรก **0%** · ถึง 3 ล้าน **15%** · เกินนั้น **20%** | ต้องมีทุนชำระแล้ว ≤ 5 ล้าน **และ** รายได้ ≤ 30 ล้านบาท |
| VAT | **7%** | ถึง **30 ก.ย. 2570** (พ.ร.ฎ. ฉบับที่ 807) อัตราตามกฎหมายคือ 10% |
| ต้องจด VAT | รายรับ **เกิน 1.8 ล้านบาท/ปี** | ภายใน 30 วันนับจากวันที่เกิน |
| หัก ณ ที่จ่าย: ค่าบริการ | **3%** | ผ่าน e-Withholding Tax เหลือ **1%** ถึง 31 ธ.ค. 2570 |
| หัก ณ ที่จ่าย: ค่าเช่า / โฆษณา / ขนส่ง | **5% / 2% / 1%** | ค่าเช่าและโฆษณาผ่าน e-WHT ก็เหลือ 1% |
| จ่ายเงินไปต่างประเทศ (ภ.ง.ด.54) | **15%** | อนุสัญญาภาษีอาจลดได้ ค่า SaaS ยังเป็นพื้นที่สีเทา [U] |
| ยื่นหัก ณ ที่จ่ายรายเดือน | วันที่ **7** (กระดาษ) · **15** (ออนไลน์) | +8 วันออนไลน์ ใช้กับแบบที่ครบกำหนดถึง 31 ม.ค. 2570 |
| ภ.ง.ด.50 (ประจำปี) | ภายใน **150 วัน** หลังปิดรอบบัญชี | ภ.ง.ด.51 (ครึ่งปี) ภายใน 2 เดือนหลังเดือนที่ 6 |
| ประกันสังคม | **5% + 5%** เพดานค่าจ้าง **17,500** | สมทบสูงสุดฝ่ายละ 875 บาท/เดือน ปี 2569–2571 |
| เก็บเอกสารบัญชี | **5 ปี** | พ.ร.บ.การบัญชี มาตรา 14 |

## 🤖 ใช้กับ AI (ตั้งค่า 2 นาที)

โฟลเดอร์ `skills/thai-accounting-tax-law/` คือ **agent skill** ที่พร้อมใช้ มันสั่งให้ AI อ้างอิงแหล่งที่มา โชว์วิธีคำนวณ บอกเรื่องที่ยังไม่ยืนยัน และเช็กวันหมดอายุของมาตรการ

**Claude Code**

```bash
git clone https://github.com/KunanonJ/thai-accounting-tax-law.git
mkdir -p ~/.claude/skills
cp -r thai-accounting-tax-law/skills/thai-accounting-tax-law ~/.claude/skills/
```

**แอป Claude, ChatGPT, Gemini, Codex, Cursor:** มีขั้นตอนละเอียดของแต่ละตัวใน[คู่มือการใช้งาน](docs/how-to-use.th.md)

จากนั้นถามได้เลย ภาษาไทยหรืออังกฤษก็ได้:

> "จ้างฟรีแลนซ์ 25,000 บาท ต้องหัก ณ ที่จ่ายเท่าไหร่ ยื่นแบบไหน ภายในวันไหน"
>
> "Paying a Thai freelancer 25,000 THB for design work. How much WHT, which form, and when?"

คำตอบที่ดีจะบอกคำตอบก่อน ตามด้วยวิธีคำนวณ ป้ายความน่าเชื่อถือ และสิ่งที่ต้องเช็กซ้ำ ถ้าคำตอบไหนไม่มีแหล่งอ้างอิง อย่าเพิ่งเชื่อ
