# คู่มือการใช้งาน

[English](how-to-use.md) · **ภาษาไทย**

คู่มือนี้อธิบายทีละขั้นตอนว่าจะอ่านคู่มือภาษีนี้อย่างไร จะเชื่อมเข้ากับผู้ช่วย AI อย่างไร และจะเช็กอย่างไรว่าคำตอบที่ได้นำไปใช้ได้จริง

---

## 1. เหมาะกับใคร

- **ผู้ก่อตั้งและเจ้าของ SME** ที่มี หจก. หรือ บจก. และอยากเข้าใจว่านักบัญชีขออะไร เพราะอะไร
- **คนทำบัญชีและแอดมิน** ที่บันทึกใบแจ้งหนี้ จ่ายเงินซัพพลายเออร์ และเตรียมยื่นภาษีรายเดือน
- **ฟรีแลนซ์ที่กำลังเปิดบริษัท** และอยากรู้ว่ามีอะไรเปลี่ยนบ้าง
- **นักพัฒนาและคนสร้าง AI** ที่อยากได้ agent ตอบคำถามภาษีไทยแบบมีแหล่งอ้างอิง ไม่ใช่เดา
- **นักบัญชีและนักกฎหมาย** ที่อยากได้ข้อมูลอ้างอิงแบบเปิด ที่ช่วยกันแก้และปรับปรุงได้

คู่มือนี้ **ไม่ได้** มาแทนนักบัญชีหรือนักกฎหมายที่มีใบอนุญาต แต่ช่วยให้คุณถามได้ตรงจุดขึ้น และจับข้อผิดพลาดได้เร็วขึ้น

## 2. ใช้ได้ 3 แบบ

| แบบ | เหมาะกับ | ใช้เวลา |
|---|---|---|
| **A. อ่านบน GitHub** | ค้นหาอะไรเร็ว ๆ | ไม่ต้องทำอะไร แค่เปิดลิงก์ |
| **B. ดาวน์โหลดเก็บไว้** | ใช้แบบออฟไลน์ แชร์ให้ทีม หรือพิมพ์ | 1 นาที |
| **C. เชื่อมกับผู้ช่วย AI** | ถามเป็นภาษาไทยหรืออังกฤษ แล้วได้คำตอบที่มีแหล่งอ้างอิง | 2–5 นาที |

### A. อ่านบน GitHub

1. เปิดหน้า repository: https://github.com/KunanonJ/thai-accounting-tax-law
2. เริ่มจาก **ตารางตัวเลขที่คนถามบ่อย** ใน README มีตัวเลขสำคัญที่สุดรวมไว้แล้ว
3. เปิดบทที่ต้องการจากตารางบท ทุกบทมีทั้งภาษาไทยและอังกฤษ
4. ใช้ **อภิธานศัพท์** (บทที่ 0) เมื่อเจอชื่อแบบฟอร์มหรือศัพท์ที่ไม่คุ้น

### B. ดาวน์โหลดเก็บไว้

- **ไม่ต้องใช้ Git:** ที่หน้า repository กดปุ่มสีเขียว **Code** → **Download ZIP** แล้วแตกไฟล์
- **ใช้ Git:**
  ```bash
  git clone https://github.com/KunanonJ/thai-accounting-tax-law.git
  ```
  ครั้งต่อไปรัน `git pull` ในโฟลเดอร์เพื่ออัปเดต

ไฟล์ทั้งหมดเป็น Markdown (`.md`) ธรรมดา เปิดได้ด้วยโปรแกรมแก้ไขข้อความทั่วไป, VS Code, Obsidian, นำเข้า Notion หรือเปิดดูบน GitHub ผ่านเบราว์เซอร์

### C. เชื่อมกับผู้ช่วย AI

โฟลเดอร์ `skills/thai-accounting-tax-law/` คือ **agent skill** ประกอบด้วยไฟล์ `SKILL.md` ที่เป็นกฎการทำงาน และโฟลเดอร์ `references/` ที่เก็บเนื้อหาคู่มือ เลือกวิธีตามเครื่องมือที่คุณใช้

#### C1. Claude Code (terminal หรือ IDE)

1. Clone repository (ดูข้อ B)
2. คัดลอกโฟลเดอร์ skill ไปไว้ในโฟลเดอร์ skills ส่วนตัว:
   ```bash
   mkdir -p ~/.claude/skills
   cp -r thai-accounting-tax-law/skills/thai-accounting-tax-law ~/.claude/skills/
   ```
   ถ้าอยากใช้เฉพาะโปรเจกต์เดียว ให้คัดลอกไปไว้ที่ `.claude/skills/` ในโปรเจกต์นั้นแทน
3. เปิด session ใหม่ของ Claude Code แล้ว Claude จะโหลด skill เองเมื่อคำถามเกี่ยวกับบัญชีหรือภาษีไทย หรือจะสั่งตรง ๆ ว่า "ใช้ skill thai-accounting-tax-law" ก็ได้
4. อัปเดตภายหลัง: รัน `git pull` ในโฟลเดอร์ที่ clone มา แล้วคัดลอกโฟลเดอร์ไปใหม่

#### C2. แอป Claude (เว็บ, เดสก์ท็อป, มือถือ)

1. ดาวน์โหลด repository เป็น ZIP (ดูข้อ B) แล้วแตกไฟล์
2. บีบอัด **เฉพาะ** โฟลเดอร์ `skills/thai-accounting-tax-law` เป็น zip ใหม่ ให้ `SKILL.md` อยู่ชั้นบนสุดของโฟลเดอร์นั้นใน zip
3. เปิดหน้าตั้งค่าของ Claude ไปที่ส่วน skills แล้วอัปโหลด zip เป็น custom skill และเปิดใช้งาน
4. เริ่มแชตใหม่แล้วถามได้เลย Claude จะใช้ skill เมื่อเกี่ยวข้อง

อีกทางเลือก: ใน **Project** ของ Claude ให้อัปโหลดไฟล์ในโฟลเดอร์ `references/` เป็นความรู้ของโปรเจกต์ (project knowledge) แล้ววางส่วน "Working rules" จาก `SKILL.md` ลงในคำสั่งของโปรเจกต์

#### C3. ผู้ช่วย AI อื่น ๆ (ChatGPT, Gemini และอื่น ๆ)

ผู้ช่วยส่วนใหญ่ให้เพิ่มไฟล์ความรู้และคำสั่งเฉพาะ (custom instructions) ใน project, custom GPT หรือ Gem ได้:

1. อัปโหลดไฟล์ใน `skills/thai-accounting-tax-law/references/` เป็นไฟล์ความรู้
2. วางส่วน **Working rules** และ **Answer format** จาก `SKILL.md` ลงใน custom instructions
3. ทดสอบด้วยตัวอย่างคำถามด้านล่าง แล้วเช็กว่าคำตอบมีแหล่งอ้างอิง

#### C4. Coding agent (Codex, Cursor และอื่น ๆ)

1. คัดลอกโฟลเดอร์ `skills/thai-accounting-tax-law/` ไปไว้ใน repository ของคุณ
2. ชี้ agent ไปที่ไฟล์นั้นจากไฟล์คำสั่งของมัน เช่นใน `AGENTS.md`:
   ```markdown
   For any question about Thai accounting, tax or business law, follow
   skills/thai-accounting-tax-law/SKILL.md and read only the reference
   chapters it points to.
   ```
3. ใน editor ที่ใช้ไฟล์ rule ให้เพิ่ม rule ที่มีประโยคเดียวกันนี้

## 3. ตัวอย่างคำถาม

ถามเป็นภาษาไทยหรืออังกฤษก็ได้ skill จะตอบตามภาษาที่คุณใช้

**ภาษีหัก ณ ที่จ่าย**
- "จ้างฟรีแลนซ์ออกแบบโลโก้ 25,000 บาท ต้องหัก ณ ที่จ่ายเท่าไหร่ ยื่นแบบไหน ภายในวันไหน"
- "I'm paying a Thai freelancer 25,000 THB for logo design. How much withholding tax, which form, and when is it due?"

**ภาษีมูลค่าเพิ่ม**
- "ยอดขายเดือนละประมาณ 160,000 บาท ต้องจด VAT เมื่อไหร่"
- "Our sales are about 160,000 THB a month. When do we have to register for VAT?"

**จ่ายเงินไปต่างประเทศ**
- "บริษัทไม่ได้จด VAT จ่ายค่าโปรแกรมจากอเมริกาเดือนละ 20 ดอลลาร์ มีภาษีอะไรต้องระวังบ้าง"
- "We're a non-VAT บจก. paying 20 USD a month for a US software tool. What Thai taxes might apply?"

**กำหนดเวลา**
- "ทำปฏิทินยื่นภาษีปี 2570 ให้หน่อย บริษัทปิดบัญชี 31 ธันวาคม มีพนักงาน 2 คน ไม่ได้จด VAT"
- "Build our 2027 filing calendar. We are a company with a 31 December year end, two employees, not VAT-registered."

**ภาษีเงินได้นิติบุคคล**
- "กำไรสุทธิ 1 ล้านบาท ทุนชำระแล้ว 1 ล้าน เสียภาษีเงินได้นิติบุคคลเท่าไหร่"
- "Our net profit is 1,000,000 THB and paid-up capital is 1M THB. How much CIT?"

**เปลี่ยนรูปแบบธุรกิจ**
- "กำลังแปรสภาพ หจก. เป็น บจก. ต้องทำอะไรบ้าง มีเรื่องไหนที่ยังไม่ชัด"
- "We are converting our หจก. into a บจก. What do we need to do and what is still unclear?"

**FlowAccount**
- "ส่งออกไฟล์ ภ.ง.ด.53 จาก FlowAccount แล้วยื่นออนไลน์ยังไง"
- "How do I export the ภ.ง.ด.53 file from FlowAccount and file it online?"

## 4. คำตอบที่ดีหน้าตาเป็นแบบไหน

คำตอบที่ดีจาก skill นี้มี 4 ส่วน:

1. **คำตอบมาก่อน:** จำนวนเงิน แบบฟอร์ม กำหนดเวลา
2. **วิธีคำนวณ:** ฐานภาษี อัตรา และผลลัพธ์ ทีละบรรทัด
3. **ป้ายและแหล่งที่มา:** ทุกกฎมีป้าย [V], [S] หรือ [U] และมีลิงก์ใน `sources.md`
4. **สิ่งที่ต้องเช็ก:** เรื่องที่มีวันหมดอายุหรือยังไม่ยืนยัน พร้อมเตือนให้นักบัญชียืนยันก่อนยื่น

ตัวอย่าง (ย่อ):

> **หัก ณ ที่จ่าย 750 บาท และโอนให้ฟรีแลนซ์ 24,250 บาท** ยื่น ภ.ง.ด.3 ภายในวันที่ 7 ของเดือนถัดไปถ้ายื่นกระดาษ หรือวันที่ 15 ถ้ายื่นออนไลน์
>
> - ฐาน: 25,000 บาท (ฟรีแลนซ์ไม่ได้จด VAT จึงไม่มี VAT)
> - อัตรา: 3% ค่าจ้างทำของ [V]
> - ภาษีหัก ณ ที่จ่าย: 25,000 × 3% = 750
> - ออกหนังสือรับรอง 50 ทวิ ให้ฟรีแลนซ์ [S]
> - ถ้าจ่ายผ่าน e-Withholding Tax อัตราเหลือ 1% (250 บาท) ถึง 31 ธ.ค. 2570 [V]
>
> เช็ก: สิทธิยื่นออนไลน์ +8 วัน ใช้กับแบบที่ครบกำหนดถึง 31 ม.ค. 2570 ให้นักบัญชียืนยันก่อนยื่น

ถ้าคำตอบ **ไม่มีแหล่งอ้างอิง** หรือบอกอัตราโดยไม่บอกว่ามาจากไหน ให้ถือว่ายังไม่ได้ตรวจสอบ

## 5. ดูยังไงว่าเชื่อได้แค่ไหน

| ถ้าเห็น | หมายถึง | ควรทำ |
|---|---|---|
| **[V]** | ตรวจกับแหล่งทางการหรือแหล่งอ้างอิงที่น่าเชื่อถือแล้ว | ใช้ได้โดยทั่วไป แต่ก่อนยื่นจริงยังควรยืนยัน |
| **[S]** | มาจากแหล่งรองที่น่าเชื่อถือ (บล็อกโปรแกรมบัญชี ข่าว ผู้เชี่ยวชาญ) | ใช้ทำความเข้าใจได้ ยืนยันก่อนลงมือ |
| **[U]** | ยังไม่ยืนยัน หรือยังมีความเห็นต่าง | ถามนักบัญชี อย่าตัดสินใจจากข้อนี้อย่างเดียว |
| **UNKNOWN / ยังไม่ชัด** | ยังหาแหล่งที่เชื่อถือได้ไม่เจอ | ถามผู้เชี่ยวชาญ หรือขอหนังสือตอบข้อหารือจากกรมสรรพากร |
| วันที่ **Last verified** | วันที่ตรวจข้อมูลครั้งล่าสุด | ถ้าผ่านมาหลายเดือน ให้เช็กเรื่องที่มีวันหมดอายุใหม่ |

ดู **ตารางมาตรการชั่วคราว** ใน[บทที่ 6](../skills/thai-accounting-tax-law/references/06-filing-calendar.th.md) ให้ดี: VAT 7%, e-WHT 1%, ยื่นออนไลน์ +8 วัน และเพดานประกันสังคม มีวันสิ้นสุดทั้งหมด

## 7. คำถามที่พบบ่อย

**ใช้ฟรีไหม?** ฟรี ใช้สัญญาอนุญาต MIT ใช้ คัดลอก แก้ไข และแชร์ได้ รวมถึงใช้เชิงพาณิชย์ แค่คงข้อความสัญญาอนุญาตไว้

**นี่คือคำปรึกษาทางกฎหมายหรือภาษีไหม?** ไม่ใช่ เป็นข้อมูลอ้างอิงที่รวบรวมจากแหล่งสาธารณะ สิ่งที่จะยื่น จ่าย หรือเซ็น ควรให้นักบัญชี ผู้สอบบัญชีรับอนุญาต หรือนักกฎหมายยืนยัน

**ทำไมฉบับหลักเป็นภาษาอังกฤษปนศัพท์ไทย?** เพื่อให้ทั้งคนไทยและชาวต่างชาติใช้ได้ โดยยังคงชื่อแบบฟอร์มจริง (ภ.ง.ด.53, ภ.พ.30) ที่เห็นในระบบกรมสรรพากร และทุกบทมีฉบับภาษาไทยเต็มให้ด้วย

**พ.ศ. กับ ค.ศ. ต่างกันยังไง?** เอกสารไทยใช้ พ.ศ. โดย พ.ศ. = ค.ศ. + 543 เช่น 2026 = 2569

**ครอบคลุมภาษีเงินได้บุคคลธรรมดาไหม?** ยังไม่ครอบคลุม ตอนนี้เน้นธุรกิจที่เป็นห้างหุ้นส่วนและบริษัท ยินดีรับการร่วมเขียน

**เจอจุดผิดต้องทำยังไง?** เปิด issue บน GitHub พร้อมแหล่งอ้างอิงที่แสดงกฎที่ถูกต้อง หรือส่ง pull request ดู [CONTRIBUTING.th.md](../CONTRIBUTING.th.md)

**ใช้ในเครื่องมือภายในบริษัทได้ไหม?** ได้ คงข้อความสัญญาอนุญาตและคำเตือนไว้ แล้วเพิ่มกฎเฉพาะของบริษัทคุณต่อได้เลย
